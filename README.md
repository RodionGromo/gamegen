# gamegen - быстрый и понятный генератор игр!
# Как запустить?
Запустите `build.py` чтоб дособрать недостающие элементы, и запускайте `main.py`<br>
# Из чего устроено?
- Сервер работает на `Python (Flask)`
- Сайт написан и украшен при помощи `Bootstrap 6`
- Генерация происходит с помощью платформы `Teamorouter`, для тестов была выбрана модель `deepseek-v4-flash-free`
